# Documentation lessons

## Portfolio README framing (2026-08-20)

### Mistake

I interpreted “portfolio website” as a reason to make the root README primarily promotional and
move operational detail into the background.

### Rule

For this project, portfolio quality means that a reviewer can quickly see both the product outcome
and the engineering depth. Keep the operational story concrete: source acquisition and fallbacks,
training and refresh cadence, data-integrity and post-deploy gates, monitoring and recovery,
evaluation/adoption discipline, and reproducible local setup. Improve ordering and readability;
do not replace those details with unsupported impact language or a shallow feature list.
